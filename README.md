# Black Squad

Website for Black Squad, a manpower agency focused on event staffing, hospitality crew, promotional teams and operational support.

## Local preview
Open `index.html` in a browser.

## Customize before launch
- Replace the placeholder contact email/phone in `index.html`.
- Update service copy to match your actual manpower offerings.
- Add your logo/assets as needed.
- Configure the contact form provider for production use.

Built as a lightweight static site with no build step.
